# Python Crash Course

Solutions to 3-months Python exercises, written while learning
the language from scratch. Each file is self-contained and runnable.

## Structure

Files are named `chapter_exercise_description.py`, so exercise 2.11
lives in `02_11_first_word_longer_than.py`.

## Running a file

    python3 chapter-02-functions-and-loops/02_11_first_word_longer_than.py

## Notes

Where an exercise had more than one reasonable approach, I've kept
the version I'd defend in a code review and noted the trade-off
in a comment.
